**创作人格代表色** 是一款微信小程序：以情境问答为线索，将日常选择映射到精心编排的人格色系之中。短短数题之后，你会获得属于自己的创作主色——附带中国传统色名、精确色值，以及一份可分享的个性创作画像。

---

## 产品亮点

- **色彩 × 人格** — 九大代表色（紫 · 蓝 · 棕 · 绿 · 黄 · 橘 · 红 · 灰 · 白），各对应一种鲜明的创作气质
- **情境化测评** — 九道生活化场景题，像故事，而非量表
- **传统色库** — 数百种中国传统色名，并标注 RGB / CMYK 专业色值
- **个性化叙事** — 生活态度、创作能量、艺术共鸣三重文案，按结果动态生成
- **即刻可分享** — 结果页视觉完整、文案可感，适合截图传播

---

## 测评流程

```
输入姓名 → 完成 9 道情境题 → 累计色彩权重 → 锁定主色调 → 生成人格画像
```

1. 输入姓名，开启旅程  
2. 回答九道贴近日常的创作情境题  
3. 每个选项会向关联色系累加权重  
4. 系统聚合得出你的主导创作色  
5. 呈现完整画像：色调解读、色块色值（RGB / CMYK）、个性叙事

## 快速开始

### 环境要求

- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 微信小程序 AppID（本地预览可使用测试号）

### 本地运行

1. 克隆仓库  
   ```bash
   git clone https://github.com/<your-org>/personalityTest.git
   cd personalityTest
   ```
2. 打开 **微信开发者工具** → **导入项目**  
3. 选择本项目目录，填写 AppID  
4. 编译后即可在模拟器或真机预览

## 设计理念

色彩不是装饰，而是气质的语言。  
本项目将「调色板」视为「人格」：用轻量、有趣的方式，把直觉变成一份可分享的创作身份。
